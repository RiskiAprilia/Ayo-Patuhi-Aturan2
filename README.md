# Ayo Patuhi Aturan

Proyek ini adalah sebuah web statis yang berisi edukasi atau panduan visual mengenai pentingnya mematuhi aturan sehari-hari, seperti di sekolah, rumah, dan lingkungan sekitar.

## 📸 Daftar Gambar Edukasi
Proyek ini memuat berbagai aset gambar ilustrasi aturan, antara lain:
- Budaya mengantre dan tidak berebut
- Duduk tertib dan mendengarkan guru
- Merapikan tempat tidur dan mainan setelah digunakan
- Mencuci tangan dengan bersih
